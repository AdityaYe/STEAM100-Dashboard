# Git Workflow Practice

This file was created to practise collaborative GitHub development.

## Workflow

1. Create a feature branch.
2. Make and review changes.
3. Commit and push the branch.
4. Open a pull request.
5. Review and merge the changes.

## Updating a Pull Request

1. Make the requested changes on the same feature branch.
2. Review and test the changes.
3. Commit the changes.
4. Push the branch to GitHub.
5. The existing pull request updates automatically.
